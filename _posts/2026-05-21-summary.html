EN

GitHub confirmed that a malicious Visual Studio Code extension installed by an employee led to unauthorized access to 3,800 internal repositories. The breach highlights the risk of supply chain attacks on popular developer tools, potentially exposing code from thousands of projects and prompting reassessment of extension security practices. The breach involved roughly 3,800 internal repositories, was triggered by a poisoned VS Code extension installed by a GitHub employee, and the malicious code was later removed, with the hacking group TeamPCP claiming responsibility.
